# Codex Workspace

여러 Codex CLI 터미널을 한 화면에서 보고, 세션 상태와 연결 계정을 함께 관리하는 Windows 개인용 앱입니다. 기존 Codex TUI를 유지하며 작업 탭마다 별도 배치를 저장합니다. OpenAI 또는 Orca의 공식 프로젝트가 아닙니다.

현재 버전은 **0.1.0 개발판**입니다. 구현 범위와 검증 상태는 [구현 현황](IMPLEMENTATION_STATUS.md)을 확인하세요. 실제 구독 계정으로 전체 흐름을 검증한 정식 릴리스는 아닙니다.

## 실행

Windows와 **Codex CLI 0.154.0**이 필요합니다. 현재 인증 연동은 이 버전으로 제한됩니다. 소스에서 실행하려면 Node.js 22 이상을 설치한 뒤 저장소에서 다음 명령을 실행하세요.

```powershell
npm ci
npm start
```

Windows 배포 파일은 `npm run dist`로 ZIP을 만듭니다. ZIP을 전부 압축 해제한 뒤 `Codex Workspace.exe`를 실행하세요. `npm run pack`으로 만든 파일은 `release/win-unpacked/Codex Workspace.exe`에서 실행할 수 있습니다. 실행 파일만 다른 폴더로 옮기면 안 됩니다.

Codex 실행 파일을 자동으로 찾지 못하면 앱을 시작하기 전에 경로를 지정할 수 있습니다.

```powershell
$env:CODEX_WORKSPACE_CODEX_PATH = 'C:\path\to\codex.exe'
npm start
```

## 처음 사용하기

1. **계정 · 사용량 → 가져오기**에서 Orca 또는 OpenCodex의 인증 JSON을 선택합니다. 접근 토큰과 갱신 토큰이 모두 들어 있어야 합니다. 앱은 실제 계정을 자동으로 찾아 가져오지 않습니다.
2. **새 세션**에서 작업 폴더를 선택합니다. 시작 계정의 기본값은 자동 선택입니다. 기존 대화는 대화 ID를 입력해 재개할 수 있습니다. 폴더 선택만으로 과거 대화가 재개되지는 않습니다.
3. 필요한 세션을 작업 탭에 배치합니다. 탭마다 열 수와 너비, 패널 순서를 조절하고 같은 세션을 여러 탭에 놓을 수 있습니다. 실제 대화와 입력 대상은 하나입니다.
4. 패널의 상태 배지와 세션 목록, 숨겨진 탭의 표시로 진행 중·응답 필요·복구·대기 상태를 확인합니다. 새 결과를 읽는 것과 **검수 완료** 표시는 별개입니다.

**패널이나 탭의 ×는 화면만 닫습니다.** 세션의 **종료**는 확인 후 실행을 끝내고 목록에서 삭제합니다. 프로젝트 파일과 저장된 대화는 삭제하지 않습니다. 앱 창을 닫아도 백그라운드 세션은 유지되며, 앱을 다시 열어 연결할 수 있습니다.

## 계정과 사용량

계정 인증은 프로젝트의 Codex 설정과 분리합니다. 계정을 바꾸려고 별도 `CODEX_HOME`을 만들지 않으므로 기존 스킬·도구·프로젝트 설정을 공유합니다. 계정별 구독, 조직 정책, 계정에 연결된 서비스의 차이까지 같아지는 것은 아닙니다.

각 세션의 CLI 인증 저장소만 메모리로 제한해 `/logout`이 공용 `auth.json`을 지우지 못하게 합니다. CLI에서 직접 로그인하거나 로그아웃하면 앱의 관리 계정 표시와 자동 복구를 해제합니다. 다시 관리하려면 앱의 계정 전환을 사용하세요.

가져온 인증정보는 Windows 사용자 계정에 묶인 DPAPI로 암호화하여 앱이 독립 관리합니다. 원본 JSON은 삭제하거나 갱신하지 않습니다. 독립 이전 후에는 원본 앱에서 해당 인증을 계속 사용하지 마세요. 두 앱이 같은 갱신 토큰을 함께 관리하는 방식은 지원하지 않습니다. 접근 토큰만 있거나 원본 앱을 참조하는 가져오기 자료는 독립 이전용으로 충분하지 않습니다.

정상 세션은 현재 계정을 유지합니다. 새 세션의 자동 선택은 사용 가능한 계정 중 남은 사용량이 있고 리셋이 가까운 계정을 우선합니다. **고정**은 계정을 유지하는 정책이고, **전환**은 계정을 바꾸는 동작입니다. 고정 상태에서 전환하면 고정이 해제된다는 안내를 표시합니다. 수동 전환은 턴 사이에 가능합니다.

사용량은 서비스 조회 결과로 갱신합니다. 백그라운드 실행 중 60초마다 조회하며 수동 새로고침도 가능합니다. 페이스메이커는 같은 리셋 구간의 관측값으로 리셋 때 남을 비율을 추정하고 전환 검토 시점을 표시합니다. 관측이 부족하면 전망을 확정하지 않습니다. 서로 다른 계정의 비율을 더해 전체 절대 용량으로 표시하지 않으며, 작업량을 강제로 제한하지도 않습니다.

자동 복구는 실패가 확인된 일부 사용량·인증·서버 혼잡 오류에 한정됩니다. 도구 실행이나 응답이 시작되지 않은 순수 텍스트 턴만 재시도 대상으로 삼고, 사용자 입력·취소·고정 변경을 확인합니다. 일부 실행이 있었거나 결과가 불명확하면 사용자의 판단을 기다립니다. 모델을 자동으로 낮추지 않습니다.

## 데이터와 업데이트

기본 데이터 폴더는 `%LOCALAPPDATA%\CodexWorkspace`입니다. **작업 공간 → 데이터 폴더 열기**에서 작업 배치와 실행 로그의 위치를 열 수 있습니다. `accounts.dpapi`는 다른 Windows 사용자에게 그대로 이전할 수 있는 계정 내보내기 파일이 아닙니다.

자동 업데이트는 비활성화되어 있습니다. 실행 중인 세션이 있으면 현재 압축 해제 폴더를 지우거나 덮어쓰지 마세요. 버전을 교체하려면 세션을 모두 종료한 다음 **작업 공간 → 백그라운드 실행부 종료**를 선택하고 새 폴더에서 실행합니다. 실행 중인 세션이 남아 있으면 실행부 종료가 거부됩니다. 운영체제 재시작이나 백그라운드 프로세스 종료 후에 실행 중인 작업을 그대로 유지하는 기능은 아닙니다.
